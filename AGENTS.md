# Project Instructions

## Secondary and Tertiary Page Overlays

Except for the secondary page `关于我-1`, all current and future secondary and tertiary pages must open as an overlay on the current page.

- Overlay background width: fixed `1280px`
- Overlay background height: content-driven, with at least the viewport height when needed
- Overlay background position: `left: 0`, `top: 0`
- Overlay background color: `#FFFBF6`
- Close icon size: `32px * 32px`
- Close icon position: `position: fixed`, `top: 24px`, `right: 24px`, `z-index: 9999`
- The close icon position must stay fixed and unchanged across these overlay pages.
